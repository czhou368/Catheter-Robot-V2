# Catheter Robot V2.0

This project is for a new version of catheter robot. The robot system is `modular`, with 2 module with 4 DoFs each (2-DoF bending + 1-DoF insertion + 1-DoF rotation), totally with `8 DoFs`.

Overall, it's a `Concentric Tendon-Driven Continuum Robot`.

Please follow the environment installation in project `catheter robot v1.0`.
